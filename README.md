# Typex

Минималистичный тренажёр скорости печати на Next.js. Тексты дня, заезды с проверкой каждого символа, история результатов, профили, достижения и рейтинги.

## Возможности

- **Заезды** — посимвольная проверка, строгий режим с блокировкой опечаток, подсчёт WPM, точности и времени, поддержка многострочных текстов, Backspace и Escape.
- **Текст дня** — один общий текст на локальную календарную дату и отдельный рейтинг за сегодня.
- **Библиотека** — 30 стартовых отрывков на русском и английском, поиск, фильтры по языку и категории, создание своих текстов.
- **Профили** — статистика, график последних заездов, история, аватары и достижения.
- **Достижения** — шесть наград, которые открываются автоматически после заездов и создания текстов.
- **Внешний вид** — тёмная и светлая темы, четыре акцента, три моноширинных шрифта, размер текста заезда.
- **Звук** — тихий сигнал при ошибке и опциональный клик при правильном нажатии на Web Audio API.
- **Рейтинг** — топ пользователей и текстов за всё время и результаты на тексте дня за сегодня.
- **Доступность** — адаптивная вёрстка, навигация с клавиатуры, семантические элементы и контрастные состояния фокуса.

## Запуск

```bash
npm install
```

Создайте `.env` в корне проекта:

```env
# Строку подключения возьми из Neon (см. раздел «Деплой»)
DATABASE_URL="postgresql://user:password@host/db?sslmode=require"
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="replace-with-a-long-random-string"
```

Подготовьте базу и загрузите стартовые данные:

```bash
npx prisma migrate dev --name init
# или, если миграции не нужны:
npm run db:push
npm run db:seed
```

Запустите приложение:

```bash
npm run dev
```

Откройте `http://localhost:3000`.

## Деплой на Vercel + Neon

1. Создайте проект и базу на [neon.tech](https://neon.tech).
2. Скопируйте строку подключения из Neon и вставьте её в локальный `.env`:
   ```env
   DATABASE_URL="postgresql://user:password@host/db?sslmode=require"
   ```
   Для serverless-окружения Vercel лучше использовать pooled-строку подключения Neon (например, с `-pooler` в хосте). Для миграций берите direct-строку без `-pooler`.
3. Примените схему и загрузите стартовые данные:
   ```bash
   npx prisma migrate dev --name init
   npm run db:seed
   ```
   Если миграции не нужны, вместо первой команды можно выполнить `npm run db:push`.
4. Запушьте репозиторий на GitHub. Файл `.env` в репозиторий не попадает — он в `.gitignore`.
5. В Vercel импортируйте репозиторий и добавьте переменные окружения:
   - `DATABASE_URL` — строка подключения из Neon;
   - `NEXTAUTH_URL` — `https://<ваш-домен>.vercel.app`;
   - `NEXTAUTH_SECRET` — длинная случайная строка (`openssl rand -base64 32`).
6. Нажмите Deploy. `@prisma/client` генерируется автоматически на этапе `postinstall`.

Для обновления схемы на уже задеплоенной базе используйте `npm run db:migrate` (применяет закоммиченные миграции) или `npm run db:push`.

## Тестовые аккаунты

После `npm run db:seed` доступны три аккаунта с паролем `password123`:

| Имя | Email | Тема | Режим |
| --- | --- | --- | --- |
| `user1` | `user1@typex.local` | тёмная, лайм | строгий, звук печати |
| `user2` | `user2@typex.local` | светлая, янтарь | свободный |
| `user3` | `user3@typex.local` | тёмная, голубой | строгий, звук печати |

У каждого аккаунта есть сохранённые заезды и открытые достижения. Повторный запуск seed обновляет тестовые данные и не удаляет остальной контент.

## Достижения

| Код | Название | Условие |
| --- | --- | --- |
| `first_race` | Первый заезд | Сохранить первый результат |
| `wpm_60` | 60 WPM | Достичь 60 WPM в одном заезде |
| `wpm_100` | 100 WPM | Достичь 100 WPM в одном заезде |
| `accuracy_100` | Заезд без ошибок | Завершить заезд со 100% точностью |
| `races_10` | 10 заездов | Сохранить десять результатов |
| `texts_3` | Создал 3 текста | Добавить три собственных текста |

Достижения проверяются после сохранения результата и после создания текста. Открытые награды отображаются в профиле, закрытые остаются приглушёнными.

## Строгий режим и звук

- Строгий режим включён по умолчанию: неверный символ не двигает курсор, ожидаемый символ вспыхивает красным, а ошибка учитывается в точности.
- В свободном режиме неверный символ принимается, как раньше, но тоже увеличивает счётчик ошибок.
- `ё` и `е`, `Ё` и `Е` взаимозаменяемы при сравнении; в тексте всегда отображается исходный символ.
- Звук при ошибке включён по умолчанию, звук печати выключен. Оба звука используют Web Audio API без внешних файлов.
- Настройки хранятся в `User.settings` для авторизованных; для гостей внешний вид и режимы сохраняются в `localStorage`.

## Как работает текст дня

- Дата определяется по локальному времени сервера в формате `YYYY-MM-DD`, без UTC-сдвига.
- Для даты создаётся одна запись `DailyText`, поэтому все пользователи видят один и тот же текст.
- Текст выбирается детерминированно из публичной библиотеки.
- Рейтинг «Сегодня» учитывает результаты на этом тексте за текущий локальный день и показывает лучший результат каждого пользователя.
